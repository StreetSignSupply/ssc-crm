# Connect the CRM worker to Google (one time)

This lets the CRM update itself in the cloud every 15 minutes. Nothing is stored and no key is created.

## Step 1: Run the setup

Click the **Copy to Cloud Shell** button on the right of the command below (the small terminal icon), then press **Enter** in the terminal.

```sh
bash g.sh
```

If a box says **Authorize Cloud Shell**, click **Authorize**.

## Step 2: Done

When the terminal shows a line starting with **DONE: projects/** followed by a long number, you're finished. Close this tab and tell Claude "done".
